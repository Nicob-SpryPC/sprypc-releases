# SpryPC downloads

**SpryPC** is a free Windows app that finds the speed your gaming PC is already capable of. It checks things like RAM running below its rated speed, a monitor stuck at 60 Hz, or power settings holding the PC back, and explains each fix in plain English.

Website: **https://sprypc.com** · Feedback: **hello@sprypc.com**

## Download

Get the latest version from **[Releases](../../releases/latest)**. Download `SpryPC-win-x64.zip`.

1. Unzip it to a folder, for example your Desktop.
2. Double-click **SpryPC.exe**.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. SpryPC is signed (publisher: Dominic Basile), but Windows shows this screen for new apps until they have been downloaded enough.
4. Click **Start scan**.

## Safe by design

- **Read-only:** it never changes a setting.
- **No admin rights.**
- **Nothing sent online:** links open only when you click them.
- **No ads, services or tray icon.**

Reviews, and how to check SpryPC for yourself: https://sprypc.com/reviews.html
